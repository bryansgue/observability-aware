Tres documentos compilables en este mismo proyecto (pdfLaTeX):

  paper_access.tex              -> manuscrito final (Main Manuscript PDF)
  paper_access_highlighted.tex  -> version resaltada, cambios en azul (Highlighted PDF)
  response_letter.tex           -> carta de respuesta a los revisores (Author's Response)

Para compilar cada uno: en Overleaf, sobre el archivo .tex -> boton derecho ->
"Set as Main File" (o Menu -> Main document), Recompile, y Download PDF.
Compilador: pdfLaTeX.
